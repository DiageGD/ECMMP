Article 1 — Visual Studio Code sur Raspberry Pi

Titre : Visual Studio Code comes to Raspberry Pi
Auteur : Ashley (avec la participation de Jim Bennett, Microsoft)
Source : Raspberry Pi
Date : 12 février 2021
Lien : Consulter l'article original sur Raspberry Pi

1. Présentation de l'article

L'article publié sur le site officiel de Raspberry Pi présente l'arrivée de Visual Studio Code sur les ordinateurs Raspberry Pi. Jusqu'alors principalement utilisé sur Windows, MacOS et Linux pour processeurs x64, l'éditeur devient également disponible avec des versions compatibles ARM et ARM64, permettant son installation sur Raspberry Pi OS.

Visual Studio Code est un éditeur de code qui peut être complété par de nombreuses extensions. Il permet notamment de travailler avec différents langages comme Python, JavaScript, TypeScript ou C/C++. Il propose également des outils de gestion de versions avec Git et peut être enrichi pour programmer des microcontrôleurs grâce à des extensions comme PlatformIO.

L'article présente notamment l'exemple du Raspberry Pi 400, sur lequel Visual Studio Code peut être utilisé avec un écran, un clavier et une souris. L'intérêt est de permettre aux utilisateurs, notamment aux débutants, de retrouver un environnement de développement complet sur un ordinateur compact et abordable. Ils peuvent ainsi utiliser le même outil pour apprendre plusieurs langages et réaliser différents types de projets.

2. Analyse des avantages et des limites

Le principal avantage de cette solution est sa polyvalence. Grâce aux extensions, Visual Studio Code peut être adapté à de nombreux langages et usages. L'utilisateur peut donc conserver un seul éditeur pour différents projets, sans devoir apprendre à utiliser plusieurs logiciels.

L'installation de cet environnement sur un Raspberry Pi permet également de profiter d'outils de développement complets sur un ordinateur de petite taille et relativement accessible.

Cependant, Visual Studio Code reste un logiciel de bureau qui fonctionne sur un système d'exploitation complet. Il faut donc disposer d'un ordinateur capable de faire fonctionner Raspberry Pi OS et l'éditeur. L'utilisation présentée dans l'article nécessite également des périphériques habituels, comme un écran et un clavier. Cette solution reste donc différente d'un environnement directement intégré à un appareil spécialisé.

3. Comparaison avec ECMMP

ECMMP reprend une partie de cette idée : proposer plusieurs outils de développement au sein d'un même environnement, plutôt que de multiplier les logiciels indépendants. Toutefois, il pousse cette intégration plus loin en fonctionnant directement sur la calculatrice NumWorks, sans nécessiter d'ordinateur externe.

Cette approche permet d'avoir un environnement de développement portable et autonome, mais impose aussi des limites importantes. L'écran de la calculatrice est beaucoup plus petit que celui d'un ordinateur, les possibilités de saisie sont différentes et les ressources disponibles sont bien plus réduites. ECMMP ne peut donc pas proposer le même confort d'utilisation ni le même choix de fonctionnalités que Visual Studio Code.

Ces deux projets montrent qu'un environnement de développement peut être adapté à des machines très différentes. Visual Studio Code cherche à rendre un ordinateur compact aussi polyvalent qu'un poste de travail classique, tandis qu'ECMMP cherche à intégrer directement les fonctions essentielles d'un éditeur de code dans une calculatrice.
